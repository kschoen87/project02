In this project, you will perform a comprehensive network security assessment of a simulated healthcare company’s infrastructure. Over approximately three weeks, you’ll produce three deliverables that build on each other:

Deliverable 1 — Network Assessment Report: Scan the network, identify vulnerabilities, and present findings with risk prioritization.
Deliverable 2 — Firewall Configuration: Redesign the network’s firewall rules to improve security while maintaining functionality.
Deliverable 3 — Remediation Plan: Create a prioritized, actionable plan for the client to fix what you found.
This project uses a “learn as you go” model, just like Project 01. You don’t need all the skills before you start:

Phase 1 (Week 11): Uses nmap and firewall skills from Labs 07–08 — you already know this
Phase 2 (Weeks 12–13): Uses vulnerability scanning — taught the same week you need it
Phase 3 (Week 13): Firewall verification and synthesis — you have all the data, now prove your rules work
Group submission: Work in your assigned groups (2 people). One member submits per group. Include both names on all documents.

Relevant SLOs:

SLO 4: Create and implement firewall rules given high-level objectives
SLO 6: Scan networks and computer systems to discover vulnerabilities
SLO 7: Secure computer systems and data from tampering and unauthorized access
SLO 8: Patch vulnerabilities in operating systems and software
Points: 175 total (75 + 50 + 50)
